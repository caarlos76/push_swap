# push_swap

El objetivo de este proyecto es ordenar una lista de números utilizando dos stacks y un conjunto limitado de comandos específicos.

## Compilación

Para compilar el proyecto, simplemente ejecuta:

```bash
make
```

## Uso

El programa se ejecuta de la siguiente manera:

```bash
./push_swap "cadena de numeros"
```

Por ejemplo:

```bash
./push_swap "3 2 1 6 5 8"
```

## Descripción

- Recibe como entrada una lista de números.
- Utiliza dos stacks y comandos limitados para ordenarlos.
- El objetivo es ordenar la lista usando el menor número de movimientos posibles.
